# テスト仕様・結果 — Privacy Asset Checker

## 1. 方針

- **端末なしで回せる単体テスト**を中心にする。集計・暗号化・CSV 解析・転送プロトコルは Flutter UI やプラグインに依存しない純 Dart として切り出し、`flutter test` で検証する
- 暗号は「往復できる」だけでなく、**既知ベクタとの一致**と**平文が残っていないこと**まで確認する
- LAN 転送は**実ソケット**を使って往復させる（モックで済ませない）
- UI は Android エミュレータで全画面を手動確認する（ウィジェットテストは置いていない）

## 2. 実行方法

```bash
flutter pub get
flutter analyze   # 警告 0
flutter test      # 7 ファイル / 81 ケース
```

### 代表的なテストケース（抜粋）

| No | 対象 | ケース | 期待結果 |

## 5. 既知の課題

| 課題 | 影響 | 対応方針 |
|---|---|---|
| iOS で iCloud バックアップから復元すると、DB は移るが Keychain の鍵は移らない | 復号できない DB だけが残り、起動エラー画面から先へ進めない | `DbKeyStore.hasDatabaseKey()` で検出し、孤立した DB を捨ててやり直せる導線を追加する（iOS リリース前に対応） |
| リリース署名が debug キーのまま | Play Console にアップロードできない | 公開前に release 署名を設定する |
